# 欢迎来到我的博客！

这是我的第一篇博客文章。我很高兴能够使用 GitHub Pages 来搭建我的个人博客。

## 为什么选择 GitHub Pages？

GitHub Pages 是一个很棒的平台，因为：

1. **免费托管** - 完全免费，无需支付服务器费用
2. **简单易用** - 只需推送代码到 GitHub 仓库
3. **支持自定义域名** - 可以使用自己的域名
4. **版本控制** - 使用 Git 管理所有内容
5. **Jekyll 支持** - 内置支持 Jekyll 静态网站生成器
